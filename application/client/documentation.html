Application Documentation

About OptiOrder

OptiOrder is an e-commerce application for a European chain of optics stores. It allows the sales staff of the company to enter customer orders and to view the orders that have been saved.

Operations Menu

After logging in with a username and a password, the operations menu is shown. Select an operation from the list and click the Access button.

Create a New Order

This operation creates a new order. How to use it:

  1. Enter the order ID, the customer full name, address, email and phone number.
  2. Check the products the customer wants to buy. When a product is checked, its quantity can be entered.
  3. Click the Create Order button.
  4. The application saves the order and shows the total price including 21% VAT.

View Orders

This operation shows the saved orders. Select one of the two options and click the Access button:

  • View all orders: shows a table with all the data of all the saved orders.
  • View one order by its ID: enter the order ID and click the Search Order button. A table with all the data of that order is shown. If the order does not exist, an error message is shown.
